# WorkoutTracker
Workout program that allows users to create exercises and record their workout information.
The application will help users organize their exercise routines and keep track of their performance.

# MVP Scope (Version 1.0)
- Create new exercises or workout activities.
- Give each exercise or machine a custom name.
- Record information such as sets, repetitions, weights, and duration depending on the exercise.
- Save and load workout information so users can access previous records.
